# Challenge 1 - Data Science: Análisis de Tiendas Alura Store

## 📘 Descripción del proyecto
Este proyecto forma parte del **programa Oracle ONE - Alura LATAM** y tiene como objetivo analizar los datos de cuatro tiendas de la cadena *Alura Store* para ayudar al **Sr. Juan a decidir cuál tienda debería vender**.

A través de la limpieza, análisis y visualización de datos, se evaluaron distintos indicadores de rendimiento comercial y satisfacción del cliente, como:
- Ingresos totales por tienda.
- Categorías de productos más y menos vendidas.
- Calificaciones promedio de los clientes.
- Productos más y menos vendidos.
- Costo de envío promedio.
- Distribución geográfica de las ventas (opcional).

El análisis fue realizado en **Google Colab**, utilizando **Python** y librerías básicas de Ciencia de Datos.

---

## 🧩 Estructura del proyecto
El proyecto está compuesto por las siguientes secciones principales:

1. **Carga y revisión de datos**  
   Importación de los cuatro archivos CSV con información de ventas.

2. **Análisis por etapas**  
   - Ingreso total por tienda.  
   - Ventas por categoría.  
   - Valoración media por tienda.  
   - Productos más y menos vendidos.  
   - Costo de envío promedio.

3. **Visualizaciones**  
   Gráficos de barras, líneas y dispersión elaborados con Matplotlib.

4. **Informe final**  
   Conclusión sobre qué tienda debería vender el Sr. Juan, justificada con datos y visualizaciones.

5. **(Extra opcional)**  
   Análisis geográfico de las ventas mediante coordenadas de latitud y longitud.
